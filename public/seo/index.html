Analyse SEO

Quelle page analyser ?

Fonctionne pour n'importe quel site public : le vôtre ou un autre. L'outil ouvre la page comme le fait Google, puis note chaque élément du référencement et propose des corrections.

Outil interne, non référencé par Google. Les notes se calculent dans votre navigateur ; les sites analysés sont chargés via ce serveur pour contourner les blocages des navigateurs entre sites.
